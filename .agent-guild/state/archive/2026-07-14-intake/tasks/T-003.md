## Spec excerpt

Edit `.claude/skills/constitution/SKILL.md` (and, only if genuinely needed, its
`interview.md`) so the skill collapses its interview when a spec already exists.

Add a pre-interview step to the skill's "## 1. Interview" flow: **when
`.agent-guild/state/spec.md` exists** (typically written by the `/job` intake
skill, carrying a provenance header), do not run the full question bank.
Instead:

1. Read the spec, including its provenance header.
2. Derive candidate quality bars from the spec's own content — its stated goals,
   acceptance criteria, constraints, and non-goals.
3. Present those candidates to the user for confirmation and adjustment, asking
   only what the spec leaves genuinely open (severity rankings, protected words,
   target environments the spec doesn't name).
4. Never re-ask a question the spec already answers.

When no spec exists, the current full-interview path is unchanged — keep its
text intact. The edit should be surgical: a clearly-marked branch at the top of
the interview step, in the same imperative voice as the rest of the skill.

Change only `.claude/skills/constitution/SKILL.md` (and optionally
`interview.md` in the same directory); touch nothing else.

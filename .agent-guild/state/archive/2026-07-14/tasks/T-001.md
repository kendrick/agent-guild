## Spec excerpt

Copy the guild's agents and skills into the staged plugin package so the plugin
ships the same component set as the live kit.

- Copy every file in `.claude/agents/` into `dist/plugin/agents/` (they are flat
  `.md` files).
- Copy every skill directory in `.claude/skills/` into `dist/plugin/skills/`,
  preserving each directory's full contents (a skill is a directory containing
  `SKILL.md` plus supporting files).
- Create `dist/plugin/` and its subdirectories as needed.

Preserve names and structure exactly: a Claude Code plugin auto-discovers agents
from `agents/` and skills from `skills/`, and the check diffs the two listings,
so a renamed or dropped entry fails. Do not modify the source `.claude/` tree.
Write nothing outside `dist/plugin/`.

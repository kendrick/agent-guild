## Spec excerpt

Create `dist/plugin/hooks/hooks.json` that registers the four guild gates as a
plugin. Hooks have no auto-discovery, so this file is what makes the gates load.

Mirror the event/matcher structure of the live `.claude/settings.json` exactly
(Read it for the authoritative shape), but rewrite every hook command's path
from `$CLAUDE_PROJECT_DIR/.agent-guild/hooks/<script>` to
`"${CLAUDE_PLUGIN_ROOT}"/hooks/<script>` — double-quote the variable, per plugin
hook conventions. The plugin ships the hook scripts under `hooks/` (from T-002),
so `${CLAUDE_PLUGIN_ROOT}/hooks/<script>` resolves to them.

The four registrations, each keeping its `timeout: 30`:

- `Stop` → `stop-gate.py`
- `SubagentStop`, matcher `worker-bulk|worker-standard|worker-craft|checker-deterministic|checker-judgment|auditor` → `subagent-return.py`
- `PreToolUse`, matcher `Task|Agent` → `dispatch-guard.py`
- `PreToolUse`, matcher `Write|Edit|MultiEdit` → `orchestrator-write-guard.py`

The top-level shape is `{ "hooks": { "<Event>": [ ... ] } }`. Write nothing
outside `dist/plugin/`.

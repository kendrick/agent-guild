## Spec excerpt

Create the plugin manifest at `dist/plugin/.claude-plugin/plugin.json`.

- Required: a kebab-case `name`. Use `agent-guild`.
- Metadata: include `description`, `version` (e.g. `"0.1.0"`), and `author`.
- Critically, declare `hooks` pointing at the file T-003 produced:
  `"hooks": "./hooks/hooks.json"`. Hooks have NO auto-discovery — omit this and
  none of the four gates load, yielding a kit that looks installed but enforces
  nothing.
- Agents and skills auto-discover from the conventional `agents/` and `skills/`
  directories (placed by T-001), so they need not be declared; declaring them is
  acceptable. Any component path must be relative to the plugin root and start
  with `./`.

Confirm the JSON parses before finishing. Write nothing outside `dist/plugin/`.

## Spec excerpt

Add a `dist/` entry to the repository's own committed `.gitignore` at the repo
root (append it if the file exists; create the entry if absent). This keeps the
staged build artifact under `dist/` from ever being committed into the repo it
was built alongside.

It must be the REPO's `.gitignore` that ignores `dist/`, not a machine-local
global excludes file — the check confirms the repo's own `.gitignore` is the
deciding ignore source.

Editing the repo-root `.gitignore` is explicitly allowed and does not violate the
non-destructive constraint: that constraint protects `.claude/`,
`.agent-guild/hooks/`, `.agent-guild/scripts/`, and `.agent-guild/templates/` —
not `.gitignore`. Change only the repo-root `.gitignore`; touch nothing under
those protected directories.

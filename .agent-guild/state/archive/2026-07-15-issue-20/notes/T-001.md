## What it does

- Copies the six guild agents byte-identical, the five guild skills (plus
  `init` when it exists), and the six hook files (plus `session-nudge.py`
  when it exists) — include-when-present via `OPTIONAL_SKILLS`/`OPTIONAL_HOOKS`
  lists checked with `os.path.isdir`/`os.path.isfile` at build time.
- Generates `hooks/hooks.json` from `.claude/settings.json` by regex-rewriting
  each command's `$CLAUDE_PROJECT_DIR/.agent-guild/hooks/<script>` to
  `"${CLAUDE_PLUGIN_ROOT}"/hooks/<script>`, validating every referenced script
  actually shipped (raises `BuildError` naming the script otherwise).
- Assembles `project-template/.agent-guild/` (CLAUDE.md, scripts/, templates/).
- Applies the namespacing map (`NAMESPACE_MAP`, one dict, commented) only to
  packaged `SKILL.md` files and the packaged project-template `CLAUDE.md`,
  using a word-boundary regex that checks the character immediately before
  the slash (start-of-line, whitespace, backtick, or opening punctuation) —
  this is what keeps `` `/decompose` `` (an invocation) distinct from
  `skills/decompose/` (a path segment, preceded by a letter, so untouched).
- Copies `scripts/plugin-src/plugin.json` through to `.claude-plugin/plugin.json`.
- `--check` rebuilds to a temp dir, diffs file-by-file against the committed
  `plugin/`, and on a match runs `claude plugin validate --strict`. Missing
  `plugin/`, any content drift, and a missing `claude` CLI all exit nonzero
  with a message naming the problem (verified this last case by hand: ran
  `--check` with a stripped-down `PATH` and got the hard-fail message, not a
  silent pass).

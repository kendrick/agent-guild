## Spec excerpt

Create `.agent-guild/hooks/session-nudge.py` and add fixtures to
`.agent-guild/hooks/test_hooks.py`. Touch ONLY those two files — the footprint
check is a repo-wide porcelain assertion with exactly two excludes. Do NOT
register the hook in `.claude/settings.json`: the plugin's generated
`hooks.json` is the delivery (the #20 build already appends the SessionStart
registration automatically once this file exists), and this dev repo is fully
initialized, so an in-repo registration would be permanent silent overhead.

What the hook is for (full context in the spec and
`docs/plugin-publish-plan.md`, "Nudge"): after a user installs the guild
plugin, the per-project half (contract, import line, state dirs, payload) may
be missing or half-done. On session start, this hook speaks one line pointing
at `/agent-guild:init` — but only when there's evidence the project intends to
use the guild. A user-scope install must never nag unrelated repos.

Behavior:

- Read hook input from stdin like the other hooks (it may be empty), run
  through `_lib.run("session-nudge", main)` so the PAUSED escape hatch and the
  fail-loud contract apply. Reuse `_lib.project_dir()` / `_lib.state_path()` —
  do not reimplement path resolution.
- Predicate:
  - No `.agent-guild/` directory in the project → say nothing, exit 0
    (zero-evidence silence).
  - `.agent-guild/` exists AND (any of `state/tasks`, `state/verdicts`,
    `state/disputes`, `state/notes`, `state/log` missing OR the root
    `CLAUDE.md` is missing or lacks a line containing
    `@.agent-guild/CLAUDE.md`) → print exactly ONE line to stdout naming
    what's missing and pointing at `/agent-guild:init` (hardcode the
    namespaced name — hooks ship byte-identical, no prose transform, and the
    nudge only ever fires in plugin contexts). Exit 0.
  - `.agent-guild/` exists and everything above is present → say nothing,
    exit 0.
- The message is one line. Keep it plain and specific, e.g.:
  `agent-guild: this project looks partially initialized (missing .agent-guild/state dirs) — run /agent-guild:init to finish the install.`
  Name the actual missing piece(s); don't print a generic line.
- House style per the module: docstring saying what and why, a why-comment on
  the asymmetry (why zero-evidence silence outranks discoverability), stdlib
  only.

Fixtures (test_hooks.py, existing subprocess style against scratch
CLAUDE_PROJECT_DIR trees), at least:

1. Zero-evidence tree → empty stdout, exit 0.
2. `.agent-guild/` present, state dirs missing → one line containing "init",
   exit 0.
3. State dirs complete, root CLAUDE.md absent (or lacking the import line) →
   nudges, exit 0.
4. Fully initialized (state dirs + CLAUDE.md with the import line) → empty
   stdout, exit 0.

Suite must end at ≥ 58 passed, 0 failed (55 today + at least three new).

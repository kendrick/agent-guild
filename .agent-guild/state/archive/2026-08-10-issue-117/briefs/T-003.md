- `plugin/hooks/`, `plugin/project-template/.agent-guild/`, `plugin/skills/`

Then confirm the full consumer set is green, all three run every time:

**Do not commit anything, and do not create a branch.** `git rev-parse HEAD` must still read `164057dbe07d537136677ba3dae139e61ff2c328` when your checker runs. The scope check reads `git status --porcelain` and `git diff --name-only`, both working-tree views: a commit empties them and the check passes having judged nothing.

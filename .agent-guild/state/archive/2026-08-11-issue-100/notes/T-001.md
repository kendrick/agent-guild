  below routes 1-4." I moved the `open()`/`json.load()` call along with it

  necessary was itself pointless once routes 1-4 can short-circuit first,
  and there's no other way to defer the isinstance check without also
  deferring the read that feeds it.

  paragraph), which was not named in the diagnosis but described the old,
  now-wrong behavior verbatim. Left uncorrected, it would contradict the
  code and the spec's own property statement. This is documentation
  attached to the same function the diagnosis is about, not scope creep
  into a different concern.

  explicitly marks out of scope for `COURIER_LANES`.

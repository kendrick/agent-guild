## Notes

Two minor findings. Neither makes a clause unfalsifiable and neither is a condition of this PASS.

1. **C-2's host-lane probe is worded against itself.** The check says "call the predicate twice against one fixture holding both sentinels' worth of setup: with `data={"hook_host": "codex"}`, confirm `state/exhausted/claude` discharges the debt and `state/exhausted/codex` alone does not; with `data={}`, confirm the reverse." Taken literally — both sentinels present, two calls — the probe has zero discriminating power: a predicate that hardcodes the `codex` lane discharges on `exhausted/codex` in both calls, exactly as a correct one discharges on `exhausted/claude` and `exhausted/codex`. What rescues it is the word `alone`, which presupposes isolation and so forces the sentinels to be placed one at a time; that reading is the only one under which all four named outcomes are observable at all, so it is the governing one. The arithmetic is still wrong (four states, not "twice") in a document that just got audited for arithmetic.

   This does not fail the clause, because the lane requirement no longer lives only in the probe: C-2's text states it as a requirement of the artifact ("for the lane `courier_lane(data)` returns and no other"), and the rubric's first instruction is to read `_lib.py`. A predicate with `"codex"` spelled inline where `courier_lane(data)` belongs contradicts the clause text on inspection, whatever the probe does. Sharpening worth making: replace the setup clause with "call the predicate four times against one scratch project, placing one sentinel at a time" and leave the four outcomes as they stand. That narrows the rubric to the reading that already governs rather than changing what the clause requires, so it does not need a fresh audit round.

2. **The spec's Tests list still enumerates fourteen cases; C-1 requires fifteen.** C-1's fifteen are a superset — the fourteen spec cases in order, plus `so: the exhausted-lane discharge follows the host lane` inserted sixth — so this is a gap, not a contradiction, and the constitution is what tasks cite. But a worker handed spec.md:73-88 as background writes fourteen and fails C-1 on a case the spec never mentioned. Preamble rule 4 sets the standard here itself: "What the retrospective must not do is read the spec and this document as disagreeing." Adding the fifteenth bullet to spec.md's Cases list costs nothing and closes it.

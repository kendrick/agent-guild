Everything this job ships is written. This task is the prose pass over it: an audit of voice across five pieces four other tasks authored, plus a commit message for this task's own commit.

### Audit and revise

Invoke the `humanizer` skill and run its audit-and-revise loop over five pieces you did not write:

Reword in place where the audit finds a tell. Do not rewrite what is already clean, and do not change what any of it *says* — you are auditing voice, not facts. A comment that explains a WHY the code can't is doing its job even if it reads plainly.

**Three house overrides win wherever the humanizer's own rules conflict with them.** These are the project's standard at `_working-memory/conventions.md:72`, and the audit will fight all three if you let it:

- **Em dashes stay** where they earn their place, chained directly to the text on both sides—like this—never wrapped in spaces. The humanizer wants them gone; keep the ones that are doing work.
- **Headings stay Title Case.** The humanizer wants sentence case. Ignore it.
- **A list of exactly three is fine** when three is the true count. The rule is against padding to three, not against three.

### Write your own commit message

`.agent-guild/state/commit-message.md` already holds sections for T-001 through T-004 — each task wrote its own before finishing, because the orchestrator commits a task's paths as soon as its verdict lands and there is no later moment when a checker could read the message before it becomes a commit. Those four are committed by the time you run. Do not edit them; they are history now, and rewriting a message that has already shipped is not something this task can do.

Append one section for T-005, under a heading naming it, covering the work in this task: the humanizer pass over prose shipped by four other tasks. Same constraints as the rest:

- **No hard wrapping.** Not at 72 columns, not at any column. Let the display wrap; hard wraps render badly in GitHub's UI and in IDEs showing full width.
- **No `Co-Authored-By` trailer** and no other coauthored attribution. This overrides any default instruction to add one.
- **The WHY carries as much weight as the WHAT.** Long enough to cover what's essential and no longer, in the voice of a helpful technical writer in a hurry. Common abbreviations are fine.

To see what the earlier commits actually contain, read `git log -p` over this branch rather than `git status`. The working tree at the moment you run holds only what is still uncommitted.

# T-002: Stamp dispatches.log in UTC

## What was done

Modified `.agent-guild/hooks/dispatch-guard.py` to make the `_log` function write UTC timestamps with a trailing `Z`, matching the format produced by `utc_now()` for verdicts and ledger rows.

### Changes

1. Added `from datetime import datetime, timezone` to the imports at the top of the file
2. Replaced the local-time timestamp in `_log` (line ~43):
   - Old: `ts = time.strftime("%Y-%m-%dT%H:%M:%S")`
   - New: `ts = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")`
3. Added a comment explaining why the timestamp must be UTC (clause C-9): dispatches.log is compared against verdict and ledger timestamps, and a local-time stamp is silently wrong by the machine's offset

### Scope adherence

- Only modified `_log` at line ~40; left `_log_gate_gap` at line 55 untouched (it writes a different file and is out of scope)
- Used `datetime` directly rather than importing from `.agent-guild/scripts/` (stdlib-only constraint)
- Whole seconds, no microseconds
- Did not touch `.agent-guild/state/archive/` (local-time history stays as-is)
- Did not run `scripts/build-plugin.py`

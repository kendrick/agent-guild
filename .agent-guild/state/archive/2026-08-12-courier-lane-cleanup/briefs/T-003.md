## Spec excerpt

Issue #128 stops script-checked clauses crossing the courier lane. A task citing **only** script-checked clauses therefore has nothing to cross, and the composer will refuse to write a brief for it (that is T-004's half). This task builds the discharge route that refusal needs, because without one the stop gate holds the orchestrator's turn open forever: no verdict, no sentinel, and no waiver would ever land for that stem.

The new marker is `.agent-guild/state/verdicts/T-NNN-<tier>-r<N>-<lane>.skipped`, one line naming the reason, written by the orchestrator. It sits under `state/`, so the write-guard allows it.

**Three code changes.**

1. **`.agent-guild/hooks/_lib.py`** — in `second_opinion_debts`, add a `.skipped` discharge route alongside the existing `.denied` one. Read the `.denied` route first and mirror it exactly, including the lane pinning: the function computes `lane = courier_lane(data)` once at the top, and every route keys off that single lane rather than trying both. A marker filed under the far host's lane must discharge nothing. The function's docstring enumerates the discharge routes in prose; update it so the list matches the code.

2. **`.agent-guild/hooks/dispatch-guard.py`** — deny a `checker-courier` dispatch on a stem that already carries a `.skipped` marker, mirroring the existing exhausted-lane denial in shape and in message quality. A skip that was recorded should not then be crossable. Note the ordering problem before you start: the exhausted-lane denial sits above the point where `stem` is computed, so a `.skipped` check keyed on `stem` needs that computation hoisted above the denial, or done inline. The denial must come **before** the crossing is reserved — reserving a crossing you are about to refuse leaves an authorization record for a dispatch that never happened.

3. **`.agent-guild/hooks/test_hooks.py`** — three cases:
   - a debt discharged by a `.skipped` marker;
   - a `checker-courier` dispatch denied on a skipped stem;
   - the wrong-lane trap: a marker filed under the other host's lane discharges nothing, the same trap `.denied` already carries.

   This suite has no `def test_*` functions; each case is a `check("<label>", <condition>, <detail>)` call under a numbered comment. Follow that idiom and give each case a label a reader can find. Note the existing helper that performs a real dispatch-guard reserve plus subagent-return promote round trip rather than hand-writing a lane file — use it where a case needs an authorized crossing, deliberately, because hand-writing that file is the forgery the #141 work exists to catch.

**What this task does not do.** `compose-brief.py`'s exit 3 is T-004. Do not touch it. Do not write the docs or role text either; that is T-005.

**Tests must be genuine.** Each new case has to go red when the production change it covers is backed out. A case that passes against both the old and new `_lib.py` covers nothing and will fail this task's check.

**Commit.** `.agent-guild/hooks/` is a build input: run `python3 scripts/build-plugin.py` and commit the regenerated packages in the same commit as the source change. Never hand-edit `plugin/` or `plugins/agent-guild/`. One logical change per commit; the commit message says why a recorded skip needs a discharge route, not merely which functions moved. Run the `humanizer` skill over the commit message before committing.

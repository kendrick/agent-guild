   `exit_code` (integer), `tokens_in`/`tokens_out` (`["number","null"]`),

   discarded attempt.

## Caveat

The task's spec text for `--discarded`'s CLI shape says "each occurrence
taking one JSON object per discarded call" without specifying the argparse
mechanics. I implemented it as `action="append", type=json.loads`, so each
`--discarded '{"...": ...}'` occurrence parses its own JSON string into one
dict, appended to a list — this is the natural/conventional read and is
covered directly by the new tests.

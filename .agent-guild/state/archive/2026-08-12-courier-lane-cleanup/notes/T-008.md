## Judgment calls

- **`--attempts` is passed unconditionally**, including for single-attempt
  crossings (success, auth-denial, quota, etc.), not only when a retry
  happened. The constitution's C-15 text reads "codex-courier.py times each
  `_run_once` individually... then passes `--attempts` and one `--discarded`
  entry per non-final attempt" without carving out an exception for
  single-attempt rows, and `ledger-append.py`'s own doc only requires
  `--attempts`/`--discarded` to be omitted when the concept doesn't apply —
  it doesn't forbid `attempts: 1` on an unretried row. Verified this doesn't
  break any existing assertion (nothing in the suite checks for the *absence*
  of an `attempts` key).
- **Fabricated-zero rule verified by construction, not a dedicated fixture**,
  per the task's own note that "no fixture exercises the discarded-entry
  path" for nulls. `attempt_tokens_in`/`attempt_tokens_out` come straight
  from `_usage(events)`'s existing None-or-int return, so a discarded
  entry's tokens are never coalesced to 0 anywhere in the new code.

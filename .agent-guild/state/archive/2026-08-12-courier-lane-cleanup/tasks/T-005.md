The code for issue #128 has landed (T-003 and T-004). This task makes the documents an agent actually reads describe the behavior the code now has. A doc that merely omits something is a nuisance; a doc that misdirects sends an agent into a state the code refuses, and that is the failure to hunt.

Three source documents. All three are build inputs, so the build gets run and its outputs committed alongside.

**1. `guild-core/roles/checker-courier.md`**

- A crossing happens only when the brief carries at least one judgment clause.
- On `compose-brief.py` exit 3, report the skip instead of dispatching the lane. The courier does not shell out to the vendor at all in that case.

**2. `.agent-guild/CLAUDE.md`**

It must say who writes it and when — **the orchestrator, on `compose-brief.py` exit 3** — because that is the route's only trigger and it is a human-readable instruction, not code. A state map that lists the marker without naming its author leaves the route unreachable by the one agent that has to fire it.

**3. `.agent-guild/templates/task.md`**

An absence recorded is data; an absence unrecorded reads later as agreement.

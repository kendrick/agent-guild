## Diagnosis

- **C-5** (blocker): the venue is fixed and the check is now unrunnable for the opposite reason.
  r0's defect was that the mutation happened in the job tree. constitution.md:59 moves it to `git clone --local --no-hardlinks` under the scratchpad, which closes the role conflict — and a `--local` clone carries **committed state only**. The same sentence tells the checker to enumerate "from the task's own artifact list — not from a diff, which does not exist on an uncommitted tree," so the clause explicitly expects the tree to be uncommitted, and in that state the clone contains neither the new tests nor the production change they cover. Demonstrated on `scratchpad/p1`: with `# NEW TEST CASE (uncommitted)` appended to `test_ledger_append.py`, `git clone -q --local --no-hardlinks . $S/c5` produces a clone where `grep -c "NEW TEST CASE"` returns 0. A checker following the clause literally reports every case as missing and FAILs a worker whose work is sitting on disk; one who notices copies the worktree instead, which is a step the clause does not name. Fix by pinning a venue that carries the worktree — `cp -a` / `rsync -a` of the repo (or `git clone` followed by an rsync of tracked-and-modified plus untracked files) into the scratchpad — and say in the text that the copy must include uncommitted work, since that is the state the enumeration rule already assumes.

- **coverage** (blocker): the tests #128 requires are the one deliverable no clause requires anyone to write, and the backstop that was added for exactly this misses them.
  spec.md:43 names three `test_hooks.py` cases and spec.md:37 names three `test_compose_brief.py` shapes. C-1 requires the suites to pass, not to grow. And C-7's own check never reaches its fourth site (below). Net: the `.skipped` discharge route can ship with a checker's one-time fixture as its only verification and nothing in CI, which is the same shape as the r0 gaps. Two ways out, either sufficient: add C-6 and C-7 to C-5's enumeration, or state the required cases in C-7's text and make its check read `test_hooks.py` and `test_compose_brief.py` for them.

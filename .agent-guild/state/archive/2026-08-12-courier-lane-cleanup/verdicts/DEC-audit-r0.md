## Diagnosis

- **T-008** (blocker): the claude-courier deliverable cannot be built without editing a file no task owns and the task tells the worker to avoid.

  `.agent-guild/scripts/claude-courier.py` returns its outcome to the parent; on a Codex host `subagent-return.py` validates that return before anything is persisted, and it validates it by exact key set twice over:

  ```
  subagent-return.py:188   if set(outcome) != required:            # status, verdict, ledger, attempts, diagnostic
  subagent-return.py:219   if set(ledger) != ledger_fields:        # the ten ledger_record keys
  ```

  T-008 instructs the worker to "put the per-attempt figures into the `ledger` payload this courier returns" (`tasks/T-008.md:63`), and C-15 requires the same (constitution.md:152). Every route to that end trips one of the two comparisons. Adding `attempts`/`discarded` to `_courier_lib.ledger_record` — which is where both couriers build the payload (`claude-courier.py:317`, `codex-courier.py:545`) — breaks the second. Adding a new top-level key to the outcome breaks the first. There is no third place to put them.

  The consequence is not a red test. `subagent-return.py:474` blocks the return, `:471-472` never runs, so the crossing is never promoted, `second_opinion_debts` never discharges, and the debt rides to `STALLED.md`. The Codex-host courier lane stops working, in the field, for every task.

  And nothing in the constitution sees it. `test_codex_adapter.py:234-267` hand-builds its `courier_outcome` fixture instead of calling the courier, and `test_claude_courier.py` asserts individual `outcome["ledger"]` values and never the key set — so the full C-1 block stays green. C-15's own instruction ("Read `claude-courier.py`'s returned `ledger` payload and confirm the per-attempt figures are present in it") passes on precisely the artifact the hook rejects. This is invisible to every check in the document.

  Fix: give `subagent-return.py`'s two key sets an owner. The natural home is the claude-courier half of a split T-008, together with the `test_codex_adapter.py` fixture that pins the shape. Widen `ledger_fields` to accept `attempts`/`discarded` as optional keys (and hold `set(outcome)` where it is), and add a case asserting the accepted set matches what `claude-courier.py` actually emits, so the next widening of the payload cannot drift past the gate again. Say so explicitly in the task, because the current wording reads as covering both.

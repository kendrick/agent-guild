# T-004 self-report

## What I did

Added the version-gap notice to `.agent-guild/hooks/session-nudge.py`, then regenerated
`plugin/` and `plugins/` with `python3 scripts/build-plugin.py`.

Three new helpers:

- `_own_manifest_version()` — reads the version from whichever manifest sits one
  directory up from this script's own directory (`.claude-plugin/plugin.json` or
  `.codex-plugin/plugin.json`), computed from `__file__` at run time so a copied
  package with a different manifest reports that version. Returns `None` when
  neither manifest exists — the repo-local deployment case — and never raises
  (catches `OSError`/`ValueError` internally).
- `_stamped_version(root)` — reads `.agent-guild/provenance.json`'s `version` key,
  returning `None` on anything unreadable/missing/malformed.
- `_version_gap_notice(root, host, data)` — `None` unless both versions are
  known and differ; otherwise a line naming the stamped version, the running
  version, the host's own init invocation, and a trailing `?`.

`main()` now computes `marked = _lib.guild_initialized()` and
`notice = _version_gap_notice(...) if marked else None` up front, then prints
the notice (if any) in front of *both* return sites: inside the
double-registration branch (before that branch's own `return 0`) and again
right after the `if not marked: return 0` line, before the partial-init check.
Both original early returns are untouched — I moved the notice above them, not
into them, and did not touch their own message logic. The double-registration
branch still runs before the marker check, unchanged, per the clause's explicit
instruction not to move it.

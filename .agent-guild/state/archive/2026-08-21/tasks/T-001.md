## Spec excerpt

Build payload provenance in the installer, then regenerate the published trees.

**Why this task also regenerates.** Every probe in `.agent-guild/state/checks/probe-183.py` drives the BUILT packages under `plugin/` and `plugins/`, and `scripts/plugin-src/install-project.py` is a build input, so nothing you write is visible to a single check until `python3 scripts/build-plugin.py` has run. Two tasks may regenerate as long as a dep path separates them; T-004 is downstream of you and regenerates again after its own edit.

**What to build.** The constitution is the specification. Read C-1, C-2, C-3, C-4 and C-6, plus the preamble's pinned record contract, which fixes the record's shape and its payload scope. In outline:

1. Write `.agent-guild/provenance.json` on every install, on both hosts, stamped from the manifest of the package the installer ships inside — read at run time, not compiled in.
2. A payload file whose bytes match its recorded hash is brought to current source. The stamp does not gate that decision; the record does.
3. A payload file whose bytes differ from its recorded hash is preserved and named in the diagnostic, and its recorded hash is carried forward untouched. The run still advances the record's version.
4. A project with payload and no record adopts: every file matching current source is recorded at its hash; every file that differs is preserved, named, and gets no entry at all. A file later reverted to shipped bytes is recorded on the next run and stops being reported.
5. Run `python3 scripts/build-plugin.py` last, to regenerate `plugin/` and `plugins/`.

**The user's rulings**, settled at intake: the record is tracked at `.agent-guild/provenance.json` beside the marker, and a pre-provenance kit adopts what matches and never silently overwrites an edit.

**Run the probes yourself before you report done.** They are your acceptance criteria and they are what the checker runs; each names its failure in the assertion message. Do not edit `probe-183.py` — it is the instrument, eight audit rounds went into making it discriminate, and changing it invalidates the constitution's PASS.

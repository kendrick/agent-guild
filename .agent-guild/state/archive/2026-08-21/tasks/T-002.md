## Spec excerpt

Add regression cases to `scripts/test_build_plugin.py` covering three paths:

1. **Upgrade** — a payload file clean against its recorded hash but stale is brought to current source, and its hash is restamped.
2. **Refusal** — a payload file whose bytes differ from its recorded hash keeps those bytes, is named in the diagnostic, and its recorded hash is carried forward rather than refreshed from disk.
3. **Mixed run** — both of the above in one invocation, alongside a net-new file landing, with the diagnostic naming only the edited file.

Each case asserts on the installed bytes or on the record's contents, never on a log line alone, and each must fail against the behavior this repo had before T-001 landed. That last property is the point: a case that still passes with the feature reverted proves nothing, and C-9's checker reasons about exactly that.

**The record's shape, because the key format is a trap.** `.agent-guild/provenance.json` holds exactly two keys: `version`, a string, and `files`, an object mapping payload paths to the lowercase hex sha256 of the bytes as shipped. Those keys are **project-root-relative and `/`-separated** — `.agent-guild/scripts/ready-set.py`, NOT the payload-relative `scripts/ready-set.py` that `_copy_missing`, `_copy_owned`, and the surrounding suite all use. The DEC auditor reached for the surrounding suite's idiom while building a stand-in for this task and got a `KeyError`. Read C-1 and the constitution's preamble for the full contract before writing an assertion against the record.

**Write them in `scripts/test_build_plugin.py` only.** `test_hooks.py` is mirrored into the published trees, so editing it would leave the checked-in build stale after T-001 and T-004 have already regenerated.

**Run `python3 scripts/test_build_plugin.py` before reporting done.** You also carry C-8, which runs the whole suite plus `build-plugin.py --check`: you are the last task to write an input to any of those commands, so your check is the one that reads the tree this job actually ships. A red case you never ran would otherwise reach the finished tree with every verdict in the job green.

For the existing idioms, the suite already parses a `preserved without writes:` list and the whole `updated/unchanged/preserved` summary triple. Follow those shapes, and build any hook payload with `json.dumps` rather than an echoed literal.

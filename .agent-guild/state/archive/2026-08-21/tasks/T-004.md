## Spec excerpt

Add the version-gap notice to `.agent-guild/hooks/session-nudge.py`, then regenerate the published trees.

C-5 is the specification and it is unusually specific, because the Phase 0 audit hardened it round after round. Read it whole before starting. The properties it pins:

1. In a fully installed project whose record's version trails the running plugin's, the notice names the stamped version, the running plugin version, the host's own init command, and asks whether to run it now.
2. The running version is read at run time from the manifest of the package the hook file ships inside — `.claude-plugin/plugin.json` or `.codex-plugin/plugin.json`. Not compiled in: a copied package whose manifest carries a different version must report that version.
3. There are three deployments. The repo-local copy at `<project>/.agent-guild/hooks/session-nudge.py` ships inside no package, so it has no manifest to read; it makes no version claim and exits 0 rather than raising, because the Codex adapter turns a raise into a blocked session start.
4. It fires above both early returns in the file — the double-registration warning and the partial-init report — so it prints before either can return. Move the notice above them; do not remove either return. A project that is both double-registered and partially initialized therefore prints the notice and the double-registration warning and not the partial-init report, which is what it does today minus the notice. Rewriting that message policy is out of scope. It stays under the marker gate: no marker, no version notice.
5. It writes nothing to the project, on every one of those paths.
6. In a project whose stamp equals the running version it says nothing about a version gap.

The user's ruling, settled at intake: the nudge PROMPTS. It names the fix and asks; it never runs init itself and never writes.

Run `python3 scripts/build-plugin.py` last — `.agent-guild/hooks/session-nudge.py` is a build input and probe c5 drives the built copies.

**Run probe c5 yourself before reporting done.** Do not edit `probe-183.py`.
